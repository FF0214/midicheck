# MIDI Check · MIDI 体检

在修改之前，先看清楚 MIDI 文件里的细节。

它适合整理 MIDI 素材、检查导出结果，以及复核生成或转写得到的 MIDI。文件在浏览器本地处理，不上传、不调用 AI，也不需要账号。

**[直接打开在线工具](https://ff0214.github.io/midicheck/)**，无需安装。也可以先点击「试试内置示例」。

## 使用方式

1. 选择或拖入 `.mid` / `.midi` 文件。可以一次添加多个文件，依次检查。
2. 在文件队列中切换文件，在音符概览中选择轨道。
3. 阅读每条提示的位置与解释。提示不等于音乐错误。
4. 勾选支持修复且你已确认的项目，先预览前后对比。
5. 下载单独的修复副本，回到 DAW 复核。原文件不会被覆盖。

没有文件时，可以点击「试试内置示例」。示例故意包含重复、重叠、未结束音符和未松开的踏板，供理解检查结果。

## 本地运行

需要 Node.js 22 或更新版本，运行网页和命令行工具不需要安装依赖。

```sh
npm run build
npm run dev
```

打开终端打印的本地地址。不要双击 HTML 直接以 `file://` 打开，浏览器会限制模块处理线程。

命令行默认只读：

```sh
node cli.mjs song.mid
node cli.mjs song.mid --json
node cli.mjs song.mid --repair-copy song.checked.mid
```

命令行修复会应用所有符合当前保守条件的重复音符和轨道结束标记修复；如需逐项选择，请使用网页。已有文件不会被覆盖。

## 如何理解提示

- **完全相同的音符事件对**：同轨、端口、通道、音高、起止 tick、力度和释放力度都相同。在无额外歧义时，可选保留一组。
- **同音重叠**：可能是连奏或音源的特定表现，不会自动裁切。
- **未找到音符结束 / 多余结束事件**：按轨道配对得到的观察，跨轨或控制器可能影响实际播放。
- **踏板未松开**：请检查尾音是否符合预期，不自动添加控制器事件。
- **缺少轨道结束标记**：可在原来的最后 tick 补入标准标记。

支持 SMF 0/1、PPQ 与 SMPTE；不支持 SMF 2、RIFF/RMID、UMP。完整限制、事件配对方法和修复条件见 [diagnostics.md](diagnostics.md)。
