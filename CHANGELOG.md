# Changelog

## 0.1.0 — 2026-10-21

- Local browser inspection and an English/Simplified Chinese interface.
- MIDI 1.0 SMF 0/1 parser and writer, PPQ and SMPTE timing.
- Explainable note, pedal, routing, tempo and end-of-track observations.
- Opt-in duplicate/EOT repairs with re-parsing and before/after preview.
- JSON report export and a read-only-by-default Node CLI.
- Synthetic demo and regression/interoperability tests.
- Public browser app on GitHub Pages.
- Mobile horizontal overflow contained; long track-name display bounded.
- Repair-preview reports use the same output filename as the MIDI download.

No independent-user compatibility results are claimed for this initial implementation.
