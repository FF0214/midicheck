# Security

The tool parses untrusted MIDI in memory. Keep the documented size/event limits and use a modern browser or maintained Node.js release. No file is executed, and no MIDI contents are uploaded by the application.

If a reproduction is not sensitive, open a minimal issue without private MIDI, credentials or local personal paths. If a report contains sensitive details, first request a private reporting channel from the maintainer without posting those details publicly. A private advisory/contact channel is not yet promised by this repository.

Supported line: 0.1.x. Reports affecting malformed-file handling, runaway memory/CPU, unsafe downloads or unintentional network access are particularly useful.
