# Roadmap

## Initial release gate

- [ ] Automated regression and independent-parser checks pass on supported Node versions.
- [ ] Browser import, preview, download and report export verified.
- [ ] Mobile layout and keyboard operation checked.
- [ ] Publish source and installation instructions.

## Evidence-led improvements

- [ ] Receive and reproduce real DAW interoperability reports with redistributable fixtures.
- [ ] Test a broader corpus of metadata, routing and encoding combinations.
- [ ] Clarify controller/all-notes-off interpretations from documented reproductions.
- [ ] Add additional report formats if users need them.

These are plans, not completed maintenance or adoption claims. Prioritize reproducible user problems over adding speculative features.
